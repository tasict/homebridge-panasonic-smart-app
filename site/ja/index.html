パナソニックの家電を
「ホーム」App で。

Panasonic Smart App の家電を「ホーム」App に追加する Homebridge プラグインです。エアコン、除湿機、空気清浄機、全熱交換器、スマートスイッチに対応し、洗濯機と衣類乾燥機は終わると知らせてくれます。家のネットワークで直接つながるときは直接やり取りし、つながらないときだけパナソニックのクラウドを使います。

ローカル優先、クラウドはバックアップ

パナソニックの無線 LAN アダプター CZ-T006 と CZ-T007 は、家のネットワークからも直接つながります。プラグインが自動で見つけ、状態の取得も操作も直接送るので、反応が速く、クラウドのリクエスト制限にもかかりません。

  1. 「ホーム」AppiPhone、iPad、Mac、HomePod
  2. HomeKit
  3. Homebridgeプラグインを実行
  4. 家のネットワーク
  5. 無線 LAN アダプターCZ-T006 または CZ-T007

アダプターにつながらないとき

そのリクエストは Panasonic Smart App のクラウド経由で送られるので、家電はそのまま使えます。家電は常にアカウントから見つけ、アダプターの IP アドレスが変わっても自動で見つけ直します。

「ホーム」App でできること

各家電はその種類のアクセサリとして表示され、実際に使える操作だけが並びます。

  • エアコン

    • 電源と、冷房・暖房・自動
    • 設定温度 16〜30 °C
    • 室温

  • 除湿機

    • 電源と目標湿度 40〜70%
    • 現在の湿度と風量
    • 衣類乾燥など、その機種のモードごとのスイッチ
    • タンクが満水になると表示
    • ナノイーと操作音のスイッチ

  • 空気清浄機

    • 電源と風量
    • PM2.5 の値と空気質
    • ナノイーのスイッチ

  • 全熱交換器

    • 電源と風量。自動風量のある機種は自動にも
    • 換気モードごとのスイッチ
    • 報告する機種では室内・室外の温度

  • スマートスイッチ

    • 回路ごとのスイッチ（1〜3 回路）
    • 「ホーム」App の「表示形式」で照明や扇風機として表示
    • 回路の操作はパナソニックのクラウド経由

  • 洗濯機・衣類乾燥機

    • 運転が終わると通知する「完了」センサー
    • オートメーション用の「運転中」センサー
    • 通知のみ。安全上、運転の開始は本体で行います

どれもほかの「ホーム」アクセサリと同じように、Siri、シーン、オートメーションで使えます。

HomeKit に出す家電を選べます

プラグインの設定画面には、Smart App アカウントのすべての家電が型番と現在の状態つきで並びます。対応する家電には「In HomeKit」スイッチがあり、オフにすると次の再起動で「ホーム」App から外れます。

あとからアカウントに追加した家電は自動で含まれます。冷蔵庫など、まだ扱えない家電は非対応と表示されます。

数分でセットアップ

  1. プラグインをインストール

    Homebridge UI のプラグイン画面で Panasonic Smart App を検索してインストールします。

  2. サインイン

    プラグイン設定を開き、Panasonic Smart App アカウントのメールアドレスとパスワードを入力して保存します。

  3. 家電を選んで再起動

    家電が現在の状態つきで並びます。HomeKit に出したくないものをオフにして、Homebridge を再起動します。

Homebridge 1.6 以降（Homebridge 2 を含む）、Node.js 18 以降で動作します。 設定項目の詳しい説明（英語）

知っておきたいこと

台湾の Smart App 向け
プラグインは台湾の Panasonic Smart App サービスを使います。先にそのアプリで家電を設定してください。
アカウントは分けるのがおすすめ
スマートフォンと Homebridge で同じアカウントを同時に使うと、片方がサインアウトされることがあります。Homebridge 用のアカウントを作り、メインのアカウントから家電を共有してください。
サインインは一度だけ
セッションは Homebridge の保存領域に保存して再利用するので、再起動のたびにパスワードを送ることはありません。
ほかのネットワーク構成
アダプターが別の VLAN にある場合は、詳細設定で家電を IP アドレスに対応づけられます。クラウドだけで使いたいときも、そこでローカル操作をオフにできます。
